# DAD 220 — Relational Database Case Study

This portfolio presents database-environment work using MySQL: schema creation, table definition, joins, updates, data import, and operational analysis. The case study uses the Quantigration RMA and fleet-maintenance scenarios to show how structured data supports business decisions.

## What this demonstrates

- Creating and selecting relational database schemas
- Defining tables, attributes, and relationships
- Joining related tables to answer business questions
- Updating records while preserving data integrity
- Importing structured data and analyzing operational patterns
- Explaining query results to nontechnical stakeholders

The public repository is intentionally documentation-focused. Original Word submissions and assignment templates remain private supporting evidence.
