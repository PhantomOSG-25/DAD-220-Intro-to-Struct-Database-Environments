# Relational Database Case Study

## Scenarios

The coursework covered employee and branch relationships, a Quantigration RMA database, and fleet-maintenance records. Together they demonstrate both transactional modeling and operational reporting.

## Technical workflow

1. Create and select a database schema.
2. Define tables with appropriate attributes and keys.
3. Load or enter structured records.
4. Use joins and filters to answer stakeholder questions.
5. Apply controlled updates and verify results.
6. Summarize patterns in language decision-makers can use.

## Professional considerations

Production database work would add version-controlled migrations, explicit primary and foreign-key constraints, indexes justified by query plans, least-privilege accounts, backup/restore testing, and automated validation. The public case study does not claim those controls were implemented in the course environment.
